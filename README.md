# Pixelated Icon Generator

[Live Demo](https://strecke.github.io/pixelated-icon-generator/)

A lightweight, vanilla web tool to draw, import, and generate pixel-art SVGs directly in your browser.

# Features
- Drawing Tools: Pen, Eraser, Fill Bucket, Color Picker, and a Rainbow brush.
- Shading: Easily add highlights or shadows with the Brighten/Darken tools.
- Transformations & Symmetry: Mirror your drawing (X/Y axis), rotate, or move the canvas.
- Image Import: Drag & Drop PNGs, JPGs, WEBPs, or SVGs directly onto the canvas to convert them into pixel art instantly.
- Export & Code Generation: Download your artwork as a .svg file or copy the raw SVG code to your clipboard.
- Local Gallery: Your designs are saved to your browser’s localStorage.
- Undo / Redo.
- Accessibility: Operable via keyboard shortcuts and optimized for screen readers.
